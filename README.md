# Static Exam Result Lookup Demo

**MRX IT SOLUTIONS** · Web & data

An unofficial exam-result lookup interface that can run on a static site.

The browser indexes results for roll-number search and offers a separate college view. Study groups have separate data, so another group can be added without changing the page layout.

[Case study (PDF)](result-checker-case-study.pdf)

## Try the demo

The sample uses the Python standard library and invented input.

```sh
python demo.py DEMO-02
```
